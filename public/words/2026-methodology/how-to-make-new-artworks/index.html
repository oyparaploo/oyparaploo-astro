How To Make New Artworks

← Writings / 2026 Methodology

Marks: new territory
Written October 31, 2026, for Reach

WHAT THIS IS

You make new artworks from nothing but your own drawings and your own photographs. A cloud session does the making: it runs in the Claude desktop app's Code tab, on Anthropic's computers rather than yours, and works from your private GitHub repository marks-new-territory.

The repository is a box of your pictures plus a set of written instructions:
- drawings: your Marks drawings
- photographs: your photographs, each name starting with its series
- bar: the two pictures you called perfect (r18i and r19), the standard every artwork must meet
- tools: the line finder from the Found Line test
- CLAUDE.md: the standing instructions every cloud session reads first
- outputs: where the finished artworks and sketches arrive

On your computer the repository is the folder:
C:\Users\botto\Documents\GitHub\marks-new-territory

A round goes the same way every time:
1. Add any new pictures.
2. Start a cloud session and paste one block.
3. Wait. The session makes 24 sketches, picks the six strongest, finishes those six at full size, and makes one page to look at.
4. Bring the results down to your computer and look.
5. Tell the next round what you liked and what you did not.

Each part is below, step by step.

PART ONE: ADD NEW PICTURES (only when you want new material)

1. Open GitHub Desktop. If the button at the top says Pull origin, press it and wait until it says Fetch origin again. Always do this first, because the cloud sessions send their artworks to GitHub and your computer needs them before you add anything.
2. Open the folder D:\PARAPLOO.COM BUILD\ADD TO NEW TERRITORY.
3. Put drawings in the DRAWINGS IN folder.
4. Put photographs in the PHOTOGRAPHS IN folder, inside a folder named for their series. The easiest way is to copy the series folder from D:\PARAPLOO.COM BUILD\LOCKED PHYSICAL ACTUAL and delete from the copy the photographs you do not want.
5. Double-click ADD TO NEW TERRITORY.bat. A black window shows each picture as it converts: about 15 seconds for a photograph, one to several minutes for a large drawing. When it says Finished, click the X at the top right of the window.
6. In GitHub Desktop, type Added pictures in the Summary box, press the blue Commit to main button, then press Push origin.

Add about thirty photographs at a time, no more, so each push stays under one gigabyte. Each original moves to the DONE folder, so nothing is lost and nothing is converted twice. LOG.txt in the same folder lists every picture ever added.

What makes good material:
- Photographs must be sharp. The rules say nothing out of focus.
- For artworks built from real lines (the Found Line idea), the photographs need thin dark things lying apart on a pale ground, not touching, in sharp focus: string, wire, twine, thin twigs, cord. With string or wire one or two millimetres thick, frame about two feet across. With cord about five millimetres thick, frame about eight feet across. A dozen such photographs would hold more usable line than every series tested so far.

PART TWO: START A ROUND

1. Open the Claude desktop app and go to the Code tab.
2. Start a NEW session. Every round gets its own new session.
3. Choose the cloud, not your computer: Environment Default, with the cloud mark.
4. Choose the repository oyparaploo/marks-new-territory.
5. Set the model to Fable 5.1 at High, and the permission to Auto.
6. Paste everything between the two marker lines below (not the marker lines themselves). Change only the line that starts with "For this round," or leave it as it is.
7. Send it and walk away. A full round takes hours. You do not need to watch.

PASTE FROM HERE
Read CLAUDE.md and do the job it describes, with these changes for this round.
Name this round by today's date, for example round-2026-11-02. If a folder of that name already exists in outputs, add -b, -c and so on. Put everything you make in outputs/ followed by the round name, with the page at index.html inside it. Never change or delete anything from earlier rounds.
For this round: nothing extra.
Do all the work yourself in this session; do not launch helpers and do not run commands in the background.
When you finish, say in plain words the name of the round folder, which six you chose, and which ideas were weak.
PASTE ENDS HERE

How to use the "For this round" line, in your own words. Some examples:
- For this round: use only the four Believable photographs and the drawing Countless Marks.
- For this round: try twenty-four ideas that each use one single photograph and nothing else.
- For this round: carry sketch 14 from round-2026-11-02 further: six versions of it, each finished at full size.
- For this round: leave behind anything that looks like a map.

PART THREE: IF A SESSION STOPS PARTWAY

The session pushes its work every few pictures, so nothing is lost. If it stops, or says it has grown heavy, it writes a file called HANDOFF.md inside its round folder.

1. Start a NEW cloud session the same way as in Part Two (same environment, repository, model and permission).
2. Paste this:

PASTE FROM HERE
Read CLAUDE.md. Then find the newest round folder in outputs that has a HANDOFF.md in it, read that file, and finish the round from where it stopped. Do not start over and do not change anything already finished. Do all the work yourself in this session; do not launch helpers and do not run commands in the background.
PASTE ENDS HERE

PART FOUR: LOOK AT WHAT WAS MADE

1. Open GitHub Desktop and press Fetch origin. When it changes to Pull origin, press that and wait. Finished artworks are large, so this can take several minutes.
2. Open the folder C:\Users\botto\Documents\GitHub\marks-new-territory\outputs and then the round's folder.
3. Double-click index.html. It opens in your web browser: the six finished artworks first, each whole with a close-up beside it at full size, then the twenty-four sketches, each with its name and one line.
4. The finished artworks themselves are the .webp files in the same folder, at full size. Any artwork too big for GitHub comes as two halves, with -left and -right in the names.
5. NOTES.md in the round folder says what was made, why the six were chosen, and which ideas were weak.

PART FIVE: TEACH THE NEXT ROUND

You can shape the next round in two ways.

For one round only: write it in the "For this round" line of the paste block (Part Two).

For every round from now on, change the standing instructions:
1. Pull first in GitHub Desktop (Part Four, step 1).
2. Open C:\Users\botto\Documents\GitHub\marks-new-territory\CLAUDE.md in Notepad (right-click it, Open with, Notepad).
3. Change it in plain words. The parts most worth keeping up to date:
- The "Leave behind" paragraph in The job. Add every kind of picture you did not like, so no round makes it again.
- The rules. Add any new rule you set, one line each.
- The bar. If an artwork becomes a new perfect, copy it into the bar folder and name it in the "What is here" list.
4. Save, then in GitHub Desktop type a summary such as Changed the instructions, press Commit to main, then Push origin.

THE RULES EVERY ROUND KEEPS (these already live in CLAUDE.md)

- Every pixel is your drawing or your photograph. Nothing generated, nothing from outside.
- Each photographic piece stays at its own pixels: only cut and turned, never enlarged.
- Nothing out of focus.
- The drawing leads from across a room; the richness is for up close, every touch smaller than the drawing's own line.
- Each artwork must be able to stand beside the two pictures in the bar folder.
- Finish by taking things away, not by adding.
- No web search, no comparing with anyone else's work.
- Already left behind (from the Magnificent 7 round): blocks, strips, rings, contours, streams, crystals, roots, shards, weaving, dabs and faces.

COST

- A Fable round at High is the most expensive kind of session. It is used here because every round is judgment and making, not mechanical work.
- Until November 4, 2026, 11:59 PM Pacific, cloud sessions are paid from your cloud credit (about $137 was left on October 31). After that they count against your plan's usage like any other session.
- Two rounds side by side are allowed (each in its own new session), but they cost twice as much at once.

WHEN SOMETHING GOES WRONG

- The black window says a picture was LEFT IN PLACE because its name is already in the repository: rename your file and run it again.
- The black window says PROBLEM: the original stays in its IN folder untouched. Send a screenshot to a new chat in the paraploo.com project.
- The black window says a picture was made smaller to fit: it would have been over 95 megabytes, which GitHub refuses, so it was reduced just enough. Nothing is lost on your computer; the original is in DONE.
- GitHub Desktop says it cannot push because there are newer changes: press Pull origin, then Push origin again.
- A cloud session asks you a question: answer it in one line. The instructions tell it not to wait for answers, so this should be rare.
- The cloud session cannot see your D drive or anything on your computer. Everything it uses must be in the repository, which is why Part One exists.
